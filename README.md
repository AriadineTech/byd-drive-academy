# BYD Drive Academy

Jogo educativo de perguntas para estudar os comandos do BYD Dolphin Mini e situações básicas de direção para a CNH categoria B.

## Como jogar
Abra `index.html` no navegador, ou publique pelo GitHub Pages. Não requer instalação.

## Publicar
Crie um repositório público no GitHub, envie `index.html` e `README.md` e habilite **Settings > Pages > Deploy from a branch > main / (root)**.

## Aviso
Projeto independente, não oficial da BYD ou Detran. Confirme os comandos exatos com o instrutor e siga a legislação vigente.
